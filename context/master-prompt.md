Θέλω να δημιουργήσω ένα αυτοματοποιημένο σύστημα συναλλαγών (Intelligent Trading System). Αρχικά θα εστιάζει στην εκτέλεση εντολών στο Forex μέσω της MetaTrader5. Το έναυσμα (trigger) για το άνοιγμα μιας θέσης θα γίνεται από την άντληση των νέων (οικονομικά ή γεωπολιτικά γεγονότα και ανακοινώσεις), από το NewAPI, που σχετίζονται άμεσα με τα νομίσματα των ισοτιμιών που είναι διαθέσιμα για συναλλαγές. Η λήψη αποφάσεων θα γίνεται με την βοήθεια της τεχνητής νοημοσύνης, κάτω από αυστηρούς κανόνες διαχείρισης ρίσκου, με στόχο να μηδενιστεί ο παράγοντας του ανθρώπινου συναισθήματος, ο οποίος όταν λειτουργεί κάτω από συνθήκες όπου υπάρχει πίεση συνηθίζει να παίρνει εσφαλμένες αποφάσεις.

Σε επόμενες φάσεις ανάπτυξης θα επεκτείνουμε το σύστημά μας ώστε, να υποστηρίζει πολλαπλές πηγές εισόδου δεδομένων (i.e. Technical Analysis from Market Data), θα εξετάσουμε την δυνατότητα χρήσης του σε άλλες αγορές (Stocks, Futures, etc) και φυσικά την εκτέλεση εντολών σε διαφορετικές πλατφόρμες συναλλαγών (Alpaca, cTrader, etc).

Κάθε βασική λειτουργία του συστήματος θα αναπτυχθεί σε modules, για να είναι πλήρως επεκτάσιμο και εύκολο στην συντήρηση αλλά και την αξιοποίηση νέων δυνατοτήτων στο μέλλον. Ως δείγμα, η λειτουργία αναζήτησης των νέων θα είναι ένα ξεχωριστό module `news_collector` και θα περιορίζεται αποκλειστικά σε αυτή την λειτουργία, η ανάλυση των νέων θα γίνεται από ξεχωριστό module `news_analyzer` που θα αξιοποιεί τα δεδομένα από την βάση που δημιουργείται από το `news_collector`, η διαχείριση των εντολών για άνοιγμα και κλείσιμο των θέσεων θα γίνεται επίσης από ξεχωριστό module κ.λ.π.

Κάθε module πρέπει να είναι αυτόνομο σε τέτοιο βαθμό που αν στο μέλλον υπάρχει δυνατότητα και διάθεση να αναπτυχθεί ακόμη και σε διαφορετική γλώσσα προγραμματισμού χωρίς να επηρεάσει το υπόλοιπο σύστημα, διαθέτοντας το αντιστοιχο API. Αυτό θα μας βοηθήσει να αναπτύξουμε προς οποιαδήποτε κατεύθυνση θέλουμε και να εκμεταλλευτούμε ενδεχομένως και νέες τεχνολογίες. Αρχικά όμως θα ξεκινήσουμε με ένα ενιαίο code base, διαχωρισμένο σε modules.

Ως κύρια γλώσσα προγραμματισμού για το core engine επιλέγω την python καθώς φαίνεται να έχει τις περισσότερες διαθέσιμες βιβλιοθήκες για τον σκοπό που αναπτύσσεται στο σύστημά μας, την οποία όμως τώρα αρχίζω και την μαθαίνω αλλά βασίζομαι στο Claude Code και την εμπειρία μου που με βοηθά να καταλάβω το συντακτικό μιας νέας γλώσσας. Όπου υπάρχει δυνατότητα, ως δείγμα στο Trading Journal, προτιμώ να χρησιμοποιηθεί PHP/Laravel.

Με βάση τις παραπάνω οδηγίες, ετοίμασε μου ένα πλάνο εκτέλεσης που ως αποτέλεσμα θα έχει ένα σύστημα με την ελάχιστη απαραίτητη λειτουργικότητα, αλλά θα είναι πλήρως λειτουργικό και θα χρησιμοποιεί
- Πηγή συλλογής νέων: NewsAPI
- Ανάλυση για λήψη απόφασης και εκτέλεσης αυτής: ΑΙ
- Πλατφόρμα συναλλαγών: MetaTrader5

Το ίδιο θα ισχύει για κάθε επόμενη φάση, δηλαδή θα προσθέτουμε λειτουργικότητα ή θα βελτιώνουμε την υπάρχουσα υλοποίηση αλλά το σύστημα θα είναι πάντα πλήρως λειτουργικό.

Για την επόμενη φάση ανάπτυξης θα λάβεις νέες οδηγίες.

Το σύστημα θα αναπτυχθεί πλήρως μέσω του code agent Claude Code, οπότε θέλω να το ετοιμάσεις στην κατάλληλη μορφή.

Φρόντισε να καλύψεις κάθε πτυχή ασφάλειας, risk management και κυρίως επεκτασιμότητας του συστήματος.
