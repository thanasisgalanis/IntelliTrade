# IntelliTrade

Αυτοματοποιημένο σύστημα συναλλαγών, στην αγορά του Forex, που χρησιμοποιεί την τεχνητή νοημοσύνη (AI) για την λήψη αποφάσεων.

> Υλοποιείται χρησιμοποιώντας την τεχνητή νοημοσύνη, με την επίβλεψη του προγραμματιστή.
